## Intro

Ez a projekt házifeladatként készült a [Kvantuminformatikai alkalmazások]
(https://portal.vik.bme.hu/kepzes/targyak/VIHIAD00/) tárgyra a 2025/26/1-es
félévben a csapatunk által:
- Hunor Kovács ([KovacsHunor](https://github.com/KovacsHunor))
- Krisztián Magyari ([MKKrisz](https://github.com/MKKrisz))
- Patrik Zsuk ([barom-eter](https://github.com/barom-eter))
- Zsombor Török ([zsotrov](https://github.com/zsotroav))

További információk és részletes dokumentáció: [https://bloch.zsotroav.dev/docs](https://bloch.zsotroav.dev/docs)

## Tech stack

Követelmények:
- NodeJS 22
- npm 10

Külső források, könyvtárak:
- [AnimeJS](https://animejs.com/) - Animation engine
- [FontAwesome](https://fontawesome.com/) - Ikonok
- [gl-matrix](https://glmatrix.net/) - Mátrix és vektor matek könyvtár
- [WebGL2](https://www.khronos.org/webgl/) - 3D animációs és rendering API

A fejlesztéshez és publikáláshoz használt eszközök:
- [neovim](https://neovim.io/) - Kód szerkesztő
- [Visual Studio Code](https://code.visualstudio.com/) - Kód szerkesztő
- [Vite](https://vite.dev/) - Build tool
- [vite-plugin-md-to-html](https://github.com/saurabhdaware/vite-plugin-md-to-html?tab=readme-ov-file) - Markdown -> HTML konvertáló a dokumentáció oldalhoz
