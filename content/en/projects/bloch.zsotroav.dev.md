## Tech stack

Requirements:
- NodeJS 22
- npm 10 

Used external resources, dependencies:
- [AnimeJS](https://animejs.com/) - Animation engine
- [FontAwesome](https://fontawesome.com/) - Icons
- [gl-matrix](https://glmatrix.net/) - Matrix and vector math library
- [WebGL2](https://www.khronos.org/webgl/) - 3D animation and rendering API

Used for development and publishing: 
- [neovim](https://neovim.io/) - Code editor
- [Visual Studio Code](https://code.visualstudio.com/) - Code editor
- [Vite](https://vite.dev/) - Build tool
- [vite-plugin-md-to-html](https://github.com/saurabhdaware/vite-plugin-md-to-html?tab=readme-ov-file) - Markdown to HTML for docs page
