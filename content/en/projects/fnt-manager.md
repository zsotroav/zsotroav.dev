## Intro
FNTManager is a fixed-height pixel font manager that works with .fnt files and
font strip images. The app is able to read from and write to both file formats.
The application is a simple Java swing GUI application (as per the requirements)
containing two views: A primary work window and a font tester window.

This project was made as the homework assignment for the "Basics of Programming
3" ([BMEVIIIAB00](https://portal.vik.bme.hu/kepzes/targyak/VIIIAB00/)) course
in the 2024/25/2 semester.

## Tech stack
* Java Swing - The GUI framework used for the application
* [FlatLaf](https://www.formdev.com/flatlaf/) - Java Swing Look and Feel library
* [JUnit 4](https://junit.org/junit4/) - Testing framework for Java

## Features
* Load and save .fnt files
* Load and save font strip images (PNG)
* Edit available characters and symbols
